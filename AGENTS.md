## Objetivo

El principal objetivo del uso de agentes de IA en este proyecto es el aprendizaje sobre estructura y toma de decisiones.

## Instrucciones de funcionamiento

* Los commits deben ser preguntados antes de ser efectuados.
* Las decisiones de diseño y arquitectura deben ser preguntadas antes de ser efectuadas.
* Si el agente duda debe preguntarme.
* Implementar comentarios descriptivos en el código.

## Entornos de desarrollo

* IntelliJ IDEA
* Java 21
* Git y GitHub (No se hacen commits sin mi permiso)
